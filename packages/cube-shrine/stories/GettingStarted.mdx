# Getting started

`@shreklabs/cube-shrine` provides three focused entrypoints:

- `@shreklabs/cube-shrine/core` for notation/model logic (Node-safe),
- `@shreklabs/cube-shrine/render` for canvas rendering helpers,
- `@shreklabs/cube-shrine/react` for optional React components/hooks.

## Install

```bash
npm install @shreklabs/cube-shrine
```

## Choose imports by runtime

```ts
import { parseNotation, normalizeAlgorithm } from "@shreklabs/cube-shrine/core";
import { drawCube } from "@shreklabs/cube-shrine/render";
import { MiniCube } from "@shreklabs/cube-shrine/react";
```

Use only `core` in server/Node environments. Use `render` in browser/canvas contexts. Add `react` only in React apps.

## Minimal core + render example

```ts
import { createSolvedCubies, parseNotation, applyRotationStep } from "@shreklabs/cube-shrine/core";
import { drawCube } from "@shreklabs/cube-shrine/render";

const cubies = createSolvedCubies();
for (const step of parseNotation("R U R' U'")) {
  applyRotationStep(cubies, step);
}

drawCube(ctx, 220, cubies);
```
